# Talevi Stories

Fila de publicação dos stories do Instagram da Talevi Imóveis (@grupotalevitelemaco).

## Como usar

1. Entre na pasta **fila**.
2. Clique em **Add file → Upload files** e arraste as artes (até 10 por vez).
3. Dê nomes em ordem: `01.jpg`, `02.jpg`, `03.jpg`… A ordem dos stories segue o nome do arquivo.
4. Clique em **Commit changes**.
5. No chat do Claude, escreva **"publica"**.

As artes publicadas são movidas para **publicados/AAAA-MM-DD/**.

## Formato das artes

- Imagem vertical 9:16 (1080×1920). JPG, PNG ou WEBP: o Claude converte para JPG antes de publicar.
- Texto, chamadas e contatos já dentro da arte. Figurinhas (link, enquete, música) não entram na publicação automática.
